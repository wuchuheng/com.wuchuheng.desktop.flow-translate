New files in src/main/ following the existing pattern.

New files

src/main/database/repositories/history.repository.ts

— create(), getById(), getAll(order DESC), updateTransaction()

src/main/ipc/history/create.ipc.ts

— Creates DB row + writes <id>.json with input text

src/main/ipc/history/updateTransaction.ipc.ts

— Updates the transaction field in the JSON file

src/main/ipc/history/getAll.ipc.ts

— Returns list of {id, createdAt, updatedAt} for navigation

src/main/ipc/history/getById.ipc.ts

— Reads and returns the full JSON content

IPC method signatures

Accessible from renderer via window.electron.history.*

history.create({ input: string }) → { id: number }

history.updateTransaction({ id: number, transaction: string }) → void

history.getAll() → { id: number, createdAt: string }[]

history.getById({ id: number }) → { input, transaction, createdAt, updatedAt }

Translation flow integration

Modified: startTranslation.ipc.ts

1. Before AI call: history.create({ input: text }) → get id

2. Stream AI chunks to renderer (unchanged)

3. After AI completes: history.updateTransaction({ id, transaction: fullText })

4. On error: send error chunk + restore event (history record stays as "pending")
