Design — Section 3: useHistory Hook

New file: src/renderer/hooks/useHistory.ts

Hook State

Internal state + return values

mode: "latest" | "history"

activeId: number | null // current history item id

showingSide: "input" | "transaction" // Ctrl+Left toggles

latestCache: string // cached "latest" text when navigating away

historyList: { id, createdAt }[] // for navigation

Key Methods

Exposed to FlowTranslate component

navigateUp() / navigateDown()

toggleSide() // Ctrl+Left

submitHistory() // Enter in history mode (lazy AI)

submitHistoryKeepOpen() // Ctrl+Enter in history mode

setLatestText(text) // called on every keystroke in "latest" mode

commitLatestAsHistory() // save cached latest as new history item

Navigate State Machine

Ctrl+↑/↓ logic

Ctrl+↑ from "latest":

cache current input → switch to "history" mode → load newest item

Ctrl+↑ from first history item:

do nothing (at oldest)

Ctrl+↓ from last history item:

switch to "latest" mode → restore cached text

Ctrl+↓ from "latest":

do nothing (can't go past latest)

Lazy AI translation trigger

When Enter or Ctrl+Left in history mode

If transaction is empty AND input is not empty:

→ Call startTranslation(input) (same as normal mode)

→ Stream result, update JSON file, then proceed with copy
