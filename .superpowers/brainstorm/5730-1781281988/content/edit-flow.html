Editing History → Auto-save + Lazy Translation

Refined flow based on your description. Two intertwined behaviors.

Behavior 1: Editing a history item

When user types while viewing history

1. User at "latest" has typed text (not yet submitted)

2. User presses Ctrl+↑ → cache latest text, show history #3

3. User edits the history text → the edited text becomes new "latest"

4. The original cached text gets saved as a new history item (input only, no transaction)

Behavior 2: Lazy AI translation on demand

Actions that check if transaction is empty

Enter / Ctrl+Enter in history mode:

→ If transaction exists → copy it (no AI)

→ If transaction is empty → 🤖 call AI, then copy

Ctrl+← / Ctrl+→ toggling to transaction side:

→ If transaction exists → show it

→ If transaction is empty → 🤖 call AI, stream result
